# The Tape — public ledger

Append-only record ledger for The Tape (thetapeff.com, @thetapeff).

Each line commits to the SHA-256 of one 2026 paper-trading slot record (predictions and prop
calls), written before the slot's first covered kickoff. Record files are revealed in 2027.
OpenTimestamps proofs sit beside the ledger lines. Verification instructions will follow.
